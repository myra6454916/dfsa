# Инструменты проверки

Скрипты для автоматической проверки модели в headless Chromium
(SwiftShader). Перед запуском: `npm i -D playwright && npx playwright
install chromium`, затем поднять статику `python3 -m http.server 8811`.

| Скрипт | Назначение |
| --- | --- |
| `shot.mjs` | снимок сцены + состояние сборки (`__ATTACH_DEBUG`) |
| `view.mjs` | снимок с заданной конфигурацией модулей |
| `ads.mjs` | удержание ПКМ и снимок вида через прицел |
| `adscheck.mjs` | проверка, что камера села точно на оптическую ось |
| `optcheck.mjs` | луч по оси каждого прицела: ищет непрозрачные перекрытия |
| `measure.mjs` | габариты всех деталей базовой модели в мм |
| `ui.mjs` | проверка нижней панели: наложения и обрезка текста |
| `sync_ui.js` | перенос правок из модуля `ui` в исполняемую копию страницы |
